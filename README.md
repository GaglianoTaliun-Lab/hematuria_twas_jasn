# hematuria TWAS

Lona-Durazo, Frida; Omachi, Kohei; Fermin, Damian; Eichinger, Felix; Troost, Jonathan P.; Lin, Meei-Hua; Dinsmore, Ian R.; Mirshahi, Tooraj; Chang, Alexander R.; Miner, Jeffrey H.; Paterson, Andrew D.; Barua, Moumita; Gagliano Taliun, Sarah A. Association of Genetically Predicted Skipping of COL4A4 Exon 27 with Hematuria and Albuminuria. JASN. 2024. DOI: 10.1681/ASN.0000000000000480

Project to perform TWAS on hematuria GWAS (UKBB with TOPMed imputations) across with the MASHR models, using S-PrediXcan and MultiXcan.

GWAS downloaded from: https://pheweb.org/UKB-TOPMed/pheno/593

MASHR eQTL and sQTL models: https://predictdb.org/post/2021/07/21/gtex-v8-models-on-eqtl-and-sqtl/

S-PrediXcan: https://github.com/hakyimlab/MetaXcan/wiki/S-PrediXcan-Command-Line-Tutorial
